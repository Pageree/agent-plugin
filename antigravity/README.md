# Pageree

Pageree lets your AI assistant publish landing pages that collect leads, then read how visitors behave and improve each page with you.

This plugin connects Antigravity to Pageree's hosted server and adds the Landing Page Guru skill, which guides the offer, copy, design, forms and measurement of a page.

## Requirements

You need a [Pageree account](https://console.pageree.com/signup). There is no API key to copy. You sign in through your browser the first time Antigravity connects.

## Try it

- Build and publish a landing page for my business with a lead form
- Send the leads from my landing page to my email
- Show me how my landing page is doing and what to change

Publishing makes a page public, so review the preview and confirm the destination before asking the agent to publish.
